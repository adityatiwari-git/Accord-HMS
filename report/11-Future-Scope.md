# 11. Future Scope

Accord-HMS can be extended without changing its basic architecture.

1. Doctor-side login and dashboard.
2. Role-based access for doctors, staff and administrators.
3. Email or SMS appointment notifications.
4. Appointment reminders.
5. Patient medical history.
6. Prescription management.
7. Doctor profile image uploads.
8. Patient document uploads.
9. Better appointment slot management.
10. PostgreSQL or another production database.
11. Secure production deployment.
12. Search/filter doctors by department.
13. Dashboard charts and appointment statistics.
14. Online payment integration.
15. API support for a mobile application.
16. Stronger production security configuration.

These improvements can be introduced gradually while keeping the current application understandable.
