## 1.2 Introduction to the Project

**Accord-HMS (Hospital Appointment & Management System)** is a Django-based web application developed as an academic project. It manages basic hospital information, patient accounts, doctors, departments and appointments through a simple web interface.

Visitors can explore hospital information, departments, doctors and the gallery. Registered patients can create an account, log in, maintain their profile, book appointments and view or cancel appointments. Hospital records can be managed through Django's built-in admin panel.

The project is intended for academic demonstration. It focuses on understanding Django fundamentals rather than trying to implement a complete production hospital information system.

## 1.3 Objectives

- Develop a working hospital appointment application using Python and Django.
- Implement patient registration, login and logout.
- Provide a patient dashboard and profile.
- Display departments and available doctors.
- Provide individual doctor and department information.
- Allow authenticated patients to book appointments.
- Validate appointment dates and times.
- Prevent duplicate active appointment slots for a doctor.
- Allow patients to view and cancel eligible appointments.
- Provide gallery and contact functionality.
- Use Django Admin for administrative record management.
- Practice database relationships, forms, views, templates and testing.
- Maintain the project using Git and GitHub.

## 1.4 Project Overview

### Visitor workflow

Home → About → Departments → Doctors → Gallery → Contact

### Patient workflow

Register → Login → Dashboard → Profile / Book Appointment / My Appointments → Logout

### Administrator workflow

Login to Django Admin → Manage departments, doctors, profiles, appointments, gallery and contact messages.

## 1.5 Project Scope

The project covers basic hospital information and appointment management. It includes authentication, patient profiles, departments, doctors, appointments, gallery content, contact messages, demo data and administrative management.

The current scope does not include online payment, electronic medical records, prescription management, SMS/email notifications, a dedicated doctor dashboard or production-grade deployment.

## 1.6 Problem Definition

Manual appointment handling can require staff to maintain registers or separate records, making searching, updating and organizing information difficult. Accord-HMS demonstrates how these basic activities can be digitized through a database-driven Django application while keeping the implementation simple enough for a student project and viva.
