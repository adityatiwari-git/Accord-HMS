# 12. Conclusion

Accord-HMS was developed as a practical Django-based Hospital Appointment & Management System. It combines frontend design, backend programming, database management, authentication and testing into one complete academic workflow.

The project implements patient registration and login, dashboards, profiles, departments, doctor profiles, appointment booking, appointment validation, appointment cancellation, gallery content, contact messages, demo data and Django Admin management.

A major goal was to keep the implementation understandable. The project uses normal Django models, views, forms, templates and built-in authentication rather than complicated patterns that would be difficult to explain during a student-level viva.

The project provided practical experience in Python, Django, HTML, CSS, Bootstrap, JavaScript, SQLite, Git and GitHub. It also strengthened understanding of requirement analysis, database relationships, validation, testing and documentation.

Overall, Accord-HMS meets the intended academic project requirements and provides a foundation that can be extended into a larger hospital-management application.
